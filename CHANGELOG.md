# Changelog

## 1.0.0

First Petal release.

- Modular engine split into storage, images, virtualization, sessions, snapshots, and
  creation modules
- SwiftUI app rebuilt on Observation, with focused view models and view components
- Testable CLI library with typed argument parsing and commands
- Linux guests: Ubuntu, Fedora, Debian and Alpine
- Suspend & resume, APFS clones and snapshots, sparse ASIF disks
- Shared folders, clipboard sharing, Rosetta, sound, NAT networking
- `petalctl` command-line tool
